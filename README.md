## 🛠️ Tech Stack & Architecture

This application is built with modern frontend tools for high performance, premium aesthetics, and responsive layout:

- **Core Framework**: React 18 (Vite-powered for rapid HMR)
- **Styling**: Tailwind CSS (Tailored custom config for neon colors, cyber borders, and keyframe animations)
- **Animations**: 
  - **GSAP**: Performance-optimized scroll triggers and timeline animations
  - **Framer Motion**: Smooth entry animations and micro-interactions
- **Scroll Rig**: **Lenis**: Smooth inertial scroll system
- **Icons**: `react-icons`

## ⚙️ Getting Started & Local Development

To run this project locally, make sure you have [Node.js](https://nodejs.org/) installed, then follow these steps:

### 1. Clone the repository
```bash
git clone https://github.com/Raiyan91200/MYProfileNEW.git
cd MYProfileNEW
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```
The application will run locally at `http://localhost:3000` (or the port defined in your environment).

### 4. Build for Production
To generate a production-ready build:
```bash
npm run build
```
The output files will be located in the `/dist` directory.
